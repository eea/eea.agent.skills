# EEA-Specific Overrides
<!-- EEA-Overrides-Version: 1.0 -->
<!-- Last-Sync: 2026-11-18 -->

## Where this applies in EEA repos

- PR descriptions and commit messages (the repo's Conventional Commits convention)
- `CHANGELOG.md` entries (date-based versioning, `YYYY-MM-DD` headings)
- Redmine/Taskman issue fields and status updates
- Release notes and user-facing documentation

Apply the rules to the whole artifact, not only the new sentences: a PR body or changelog entry that was partly written by an agent carries the tells in the old parts too.
